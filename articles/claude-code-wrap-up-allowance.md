## 本記事について

Claude Codeに大きめの直しを頼んで、しばらくして見に行ったら「上限に達しました」で止まっていた。しかも、ファイルが半分だけ書き換わっていて、動かない。有料プランでClaude Codeを使っていると、思い当たる場面があるかもしれません。

この問題に、Anthropicが手を打ちました。「Wrap-Up Allowance」という仕組みで、直訳すると「仕上げのための取り分」です。上限に達しても少しだけ作業を続け、きりのいいところで止まります。

## 1. Claudeの「上限」をおさらい

Claudeの有料プランには、使える量の上限が2つあります。5時間ごとの上限と、1週間ごとの上限です。どちらかに達すると、枠が戻るまで使えません。上限に達したときは、いつ戻るかが画面に出ます。

この枠は、claude.aiでのチャットとClaude Codeで共通です。モデルを切り替えても、同じ枠から減っていきます。プランごとの枠の大きさは、公式の説明ページには書かれていません。

## 2. 何が変わったか

### これまで

作業の途中で5時間の上限に達すると、Claudeはその場で止まっていました。3つのファイルを直す作業なら、2つ目まで終わったところで止まり、3つ目だけが古いまま残ることがあります。開発元も、作業を中途半端な状態で急に止めるのは良い体験ではなかった、と認めています。

### これから

![これまでとこれからの比較](/images/claude-code-wrap-up-allowance/before-after.png)
*上がこれまで、下がこれから（模式図）*

応答の途中で5時間の上限に達しても、Claude Codeは少しだけ作業を続けます。仕上げが終わるのは、応答が最後まで終わったとき、取り分を使い切ったとき、自分で途中で止めたとき、のどれかです。取り分を使い切った場合は、そのとき進めていた1手を最後までやり、次の手には進みません。

### ポイント

- 取り分は少量で、上限があります。量はプランで違い、数字は公開されていません
- ヘルプには「作業を終えるのに足りるとは限らない」と書かれています
- 仕上げに使った分は、1週間の上限に数えられます。1週間の上限そのものは増えません

細かい条件は、[Claude Code Wrap-Up Allowance（Claudeヘルプ、英語）](https://support.claude.com/en/articles/17040437-claude-code-wrap-up-allowance)に書かれています。

## 3. プランごとの違い

![プランごとの違い](/images/claude-code-wrap-up-allowance/plans.png)
*あなたのプランでは？*

| プラン・使い方 | 使える回数 |
|---|---|
| Pro | 1週間に1回まで（取り分を使い切らなくても1回と数える） |
| Max | 5時間の上限に達するたび（1週間の上限の範囲内） |
| TeamのPremium席 | 5時間の上限に達するたび（1週間の上限の範囲内） |
| APIキー、Amazon Bedrock、Google CloudのVertex AI | 対象外 |
| claude.aiやアプリのチャット | 対象外（Claude Codeだけ） |

### ポイント

- 対象は、上限に達した時点で動いていた応答だけです。上限に達したあとに新しく送ったメッセージは対象外です
- アカウントと組織が作られてから、一定の期間がたっていることも条件です。この期間は公開されていません
- 段階的に提供している最中で、まだ届いていないアカウントもあります

## 4. 今日からやっておくこと

### Claude Codeの版を確かめる

```
claude --version
```

2.1.277より古ければ、更新しておきます。

### 覚えておくこと

Proの人は、仕上げは1週間に1回だけです。同じ週に2回目の上限に達すると、これまでどおりその場で止まります。止まったあとは、どこまで進んだかを自分で確かめるのが確実です。

上限に達したあとも続けたいときは、Claude Codeで`/rate-limit-options`と打ちます。上限が戻るのを待って自動で再開する、追加の利用を足す、プランを上げる、の3つから選べます。

## 5. 気をつけること

仕上げの仕組みは自動で働き、前もって申し込むことも、ためておくことも、次に持ち越すこともできません。プランに含まれる機能ではなく、Anthropicの判断で提供されるもので、予告なく変更・停止・終了することがある、と書かれています。

追加の利用（usage credits）をオンにしている人は、まず仕上げの取り分を使い、そのあとは追加の利用に切り替わって、通常の料金のまま続く仕組みです。

## 使い分けの目安

| 困っていること | やること |
|---|---|
| 上限で直しかけのまま止まるのが怖い | Claude Codeを2.1.277以降にしておく（あとは自動） |
| Proで、同じ週に2回目の上限に達した | `/rate-limit-options`で、待つか追加の利用を足すかを選ぶ |
| 止まったところから、別のAIで続けたい | 下のsession-relay |

## 宣伝：止まった会話の続きはsession-relayで

仕上げの取り分を使い切ったあとは、上限が戻るまで待つことになります。待てないときの手は、別のAIで続きをやることです。

session-relayは、新しいチャットに「続きから」と打つだけで、前の会話を引き継ぐ道具です。新しいAIが前の会話を自分で読みに行き、続きから始めます。引き継ぎ書は書きません。Claude CodeとCodexの間でも移せます。

入れ方は、ターミナルで次の2行です。

```
npm install -g @shoujiki-panman/session-relay
relay install
```

詳しくは[前に書いた記事](https://zenn.dev/shoujiki_panman/articles/session-relay-no-handoff)にまとめています。
